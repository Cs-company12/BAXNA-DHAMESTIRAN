Sida Loo Hagaajiyo Sync-ka Multi-Device

Sabab ugu badan: table-yada relational-ka ah (patients, appointments, iwm) weli lama abuurin Supabase gudihiisa, ama Realtime lama dhajin.
Tallaabo 1 — Koobiyee SQL-ka supabase_schema.sql

SQL-kani wuu dheer yahay (17 table) — fadlan isticmaal faylka supabase_schema.sql ee lagu siiyay ZIP-ka/chat-ka, ee ha isku dayin inaad halkan ka koobiyeyso.

Tallaabo 2 — Ku Shub Supabase
  1. Fur supabase.com/dashboard → dooro project-kaaga (tpmsyyhrnciqqcxlfamr)
  2. Dhinaca bidix, riix SQL Editor → New query
  3. Ku dheji (Paste) SQL-ka aad koobiyeysay → riix Run
  4. Ku soo laab app-kan, riix "Tijaabi Mar Kale" hoose
Tallaabo 3 — Xaqiiji Realtime (haddii weli aan shaqeynayn)

Supabase Dashboard → Database → Replication → hubi in bax_app_data uu ku jiro liiska Realtime-ka ee ON. Haddii uusan ku jirin, riix toggle-ka si aad u dhajiso.
